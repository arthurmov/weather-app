## 🌦 Weather App

A simple and elegant weather application built with HTML, CSS, and JavaScript that allows users to check the current weather in any city worldwide.

🔹 Real-time weather data fetched from OpenWeatherMap API
🔹 Minimalist and responsive UI for a smooth experience
🔹 Displays temperature, weather conditions, humidity, and wind speed

## 🚀 Features

✔ Search any city to get real-time weather updates
✔ Temperature, weather condition, humidity, and wind speed displayed dynamically
✔ Smooth animations and responsive design for all screen sizes
✔ Error handling for invalid city names
✔ Attractive weather icons based on real-time conditions
